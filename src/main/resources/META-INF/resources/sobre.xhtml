Sobre o sistema

Implementação do sistema descrito no artigo "Aplicação de Raciocínio Baseado em Casos no suporte a decisão de um sistema web de help desk" (Diego Joel Pilger e Marcel Hugo — FURB, 2012).

Técnicas de RBC utilizadas

  • Representação dos casos: atributo-valor.
  • Medida de similaridade: simétrica (sim(A,B) = sim(B,A)).
  • Similaridade global: vizinho mais próximo (nearest neighbour) ponderado.
  • Similaridade local numérica: escalar, 1 − |a − b| / (máximo − mínimo).
  • Similaridade local texto: contagem de palavras em comum, com o dicionário de dados.
  • Recuperação: sequencial.
  • Adaptação: substitucional.
  • Retenção: das soluções pelos problemas descritos.

Tecnologias

Java 11, Spring Boot, JSF com PrimeFaces, JPA (Hibernate) no padrão MVC, com PostgreSQL ou H2.
